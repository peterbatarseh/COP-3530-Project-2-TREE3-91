# Building the Webpage

1. Open a terminal in the project folder and run:

   ```
   python build.py
   ```

2. When it asks which program to build, type `3` (ExportWeb) and press Enter.

3. A new terminal window will open and show a message like this:

   ```
   Local server at http://127.0.0.1:8000/ - Stops when you close the terminal.
   ```

4. Copy the link from that message (`http://127.0.0.1:8000/`) and paste it into your browser.

Keep that terminal window open while you use the webpage. Closing it stops the server.
